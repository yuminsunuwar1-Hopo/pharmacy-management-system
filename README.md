# Pharmacy Management System

A web-based pharmacy management system (BCA project, Bhaktapur Multiple Campus).

**Stack:** React (Vite) · PHP (PDO) · MySQL · XAMPP

## Run locally
1. Start Apache and MySQL in XAMPP.
2. Place this folder in `C:\xampp\htdocs\`.
3. `cd frontend && npm install && npm run dev`
4. Open http://localhost:5173
